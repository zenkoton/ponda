# 04 · TUI 交互界面（`ponda tui`）

> readme 的 tui 扩展：三栏布局的终端对话界面。本文给出布局规格、面板行为、弹窗系统、键位与组件映射。TUI 直接改造 fork 内的 pi TUI（00 §1.1，三栏布局并入其渲染循环），进程模型依托 daemon（05 §5）。

## 1. 模块目标与需求映射

| readme 需求 | 本文章节 |
|---|---|
| `ponda tui` 进入对话页面 | §2 |
| 左栏：按工作区分的历史会话、上下文 token 消耗 | §4.1 |
| 左栏底部：当前 agent 与所有 agent 的 token 量与费用 | §4.3 |
| 左栏切换到文件列表；文件夹逐级展开；点文件在主体展开 | §4.2 |
| 中栏：markdown 渲染、代码高亮、图片、表格、数学公式 | §5.2 |
| 思考折叠、子步骤折叠 | §5.3 |
| 输入窗口：@引用文件、/命令、模型/思考强度/上下文窗口/模式显示与切换 | §5.4 |
| 对话窗口上方显示活跃子 agent，可切换对话 | §5.5 |
| markdown 文件超链接 → 主体显示，标签页切换 | §5.6 |
| 右栏：todolist、子任务进度与完成状态 | §4.3 |
| 任务权限申请弹窗快速选择 | §6 |

## 2. 进程与架构

```
ponda tui（前台进程，改造自 fork 内 pi 的 TUI：三栏布局并入其渲染循环）
  ├─ 启动：确定环境上下文（--env / 当前激活）→ 确认/懒启动该环境 daemon（05 §5.1）
  ├─ 连接 Unix socket，RPC：session.list/attach/send、permission.respond...
  └─ 本地状态：UI 偏好（栏宽、折叠态、主题）存 ~/.ponda/tui.json
```

- fork 收益：三栏布局作为 pi TUI 的**原生布局模式**实现（复用其消息渲染/编辑器/主题体系），而非旁挂应用；`pi` 原有单栏界面仍可用（`ponda pi` 透传）。
- TUI 崩溃/退出不影响后台任务（agent 存活于 daemon）；重进自动 attach 上次会话。
- 组件自上而下：`App(VStack[ Header, Main(HStack[LeftPanel, CenterPanel, RightPanel]), StatusBar ])`，弹窗为 Overlay。
- 尺寸自适应：终端 < 100 列时右栏折叠为 2 列状态条；< 70 列时左栏收为标签页入口（`Tab` 循环焦点）。

## 4. 左栏与右栏

### 4.1 会话视图（左栏默认页签）

- 数据源：daemon `session.list` + history 索引（02 §8），**按 workspace 分组**折叠树。
- 每条会话行：标题摘要、`tokens`（该会话累计输入+输出，附上下文窗口占用比）、状态点（running ● / detached ◐ / ended ○ / waiting-confirmation ⚠）。
- 操作：`Enter` attach（05 §5.2 语义）、`d` 删除（确认）、`f` fork、`/` 过滤。
- 顶部两个页签 `会话 | 文件` 切换（`Tab` 在页签间循环）。

### 4.2 文件视图（左栏第二页签）

- 当前会话 workspace 的文件树，文件夹 `Enter` 逐级展开/收起；`.wiki/`、`.ponda/` 可配置显示。
- `Enter` 点击文件 → 中栏以**标签页**打开（§5.6）；目录支持 `g` 跳转（fzf 式过滤）。

### 4.3 左栏底部与右栏

- **左栏底部**（状态条上方的小结区）：当前 agent（当前会话）与该环境全部 agent 的累计 token/费用（数据源 `cost.snapshot`，05 §5.3）。readme："下方是当前agent和所有agent已经消耗的token量和费用"。
- **右栏**（垂直三段，自上而下）：
  1. **TODOLIST**：当前会话任务的看板（05 §2），进度条（▓/░）+ 状态计数；`Enter` 展开子项细节。
  2. **成果状态**：goal 任务的 DeliverableSpec 表（05 §4）——readme"状态在执行过程中会一直展示在右边栏"；含最近校准结果（✔/✘/—）与 `changed-pending` 的醒目标记。
  3. **权限/通知**：待应答权限申请计数、最近事件（后台任务完成等）。非 goal 会话时第 2 段折叠。

## 5. 中栏（对话主体）

### 5.1 标签页系统

中栏顶部标签页行：会话主视图 + 打开的文件（名称 × 关闭符）。`Ctrl-Tab` / `Ctrl-<n>` 切换；readme"点击不同的标签页可以实现切换"。

### 5.2 渲染能力

| 能力 | 方案 |
|---|---|
| Markdown（标题/列表/引用/表格） | pi-tui Markdown 组件原生 |
| 代码块语法高亮 | pi-tui（主题 syntax 色板随环境主题） |
| 图片 | pi-tui Kitty/iTerm2 协议；不支持时占位符 `[img: name WxH]` |
| Mermaid | pi-tui 内置支持（降级为代码块） |
| 数学公式 | 两级：行内/简单公式 Unicode 近似渲染（x²、√、∑ 等）；复杂公式渲染为高对比等宽块 + 提示（开放问题 Q4，00 §9） |

### 5.3 折叠交互

- **思考折叠**：reasoning 消息默认折叠为一行 `▸ 思考 (2.3k tok)`，`Enter`/点击展开；跟随环境主题 userMessage/tool 色板区分。
- **子步骤折叠**：连续的工具调用-结果对折叠为 `▸ bash: npm test (✔ 3.2s)` 行组；失败（✘）默认展开。同类聚合超过 5 条再折叠为组（`▸ 5× edit`）。

### 5.4 输入区

- 多行编辑器（pi-tui Editor），`Enter` 发送 / `Shift-Enter`（或可配置）换行。
- **@ 引用**：键入 `@` 弹出文件路径补全（当前 workspace，fzf 式渐进过滤，含 `.wiki/`）；选中即插入 `[name](abs/path)` 形态的超链接 + 附件语义（该文件内容随消息附给 agent，受上下文预算截断策略）。
- **/ 命令**：补全当前环境可用命令（pi `/skill:*`、`/mcp`、`/compact` 等 + ponda 注入的 `/goal`、`/mode`、`/wiki-rebuild`）。
- **状态行**（输入框下方一行）：`mode: plan|approve|full-auto`（`Ctrl-M` 循环切换，03 §7.3 语义）、思考强度（`Ctrl-T`）、当前模型（`Ctrl-P m` 切换）、当前上下文占用 `12k/200k`（超 80% 变色，提示 `/compact`）。

### 5.5 活跃子 agent 切换条（输入区上方）

- 数据源 `swarm_status()`（05 §6.2）：每个 cell 一个 chip（角色名 + 状态色点 + 费用微标）。
- `Enter`/点击 → 中栏切换为该子 agent 会话视图（可插话 = 向其信箱发消息）；主会话 chip 固定在最左。

### 5.6 文件超链接

- 对话/文件中的相对或绝对路径 markdown 链接（含 @ 引用产物）可 `Enter`/点击 → 中栏新标签页打开该文件（滚动到链接锚点若给）；标签页内同样走 §5.2 渲染（markdown 预览）或源码高亮。

## 6. 弹窗系统（Overlay）

统一弹窗组件（pi-tui Overlay + SelectList），类型与交互：

| 弹窗 | 触发 | 选项 |
|---|---|---|
| 权限申请（03 §7.2） | sandbox-guard 越权 | `允许一次 / 本会话允许 / 总是允许(写回 manifest) / 拒绝 / 自定义(编辑命令)` |
| 合并/结算确认（03 §6.3） | 沙箱结算 | `逐文件 diff 视图 → apply / discard / 部分勾选` |
| 成果契约确认（05 §4.1） | goal planning 完成 | 清单审阅视图 → `确认 / 编辑后确认(改判据) / 打回重新计划` |
| 契约变更审批（05 §4.3） | change_request | diff 视图 → `批准 / 拒绝` |
| 模式切换确认 | 放宽权限模式 | `确认 / 取消` |

弹窗期间后台流继续（事件入队列，关闭后补渲染）；同一时刻多个待确认按队列逐个处理，右栏显示排队计数。

## 7. 键位总表（默认，可经 `~/.ponda/tui.json` 改）

| 键 | 焦点区 | 动作 |
|---|---|---|
| `Tab` / `Shift-Tab` | 全局 | 左栏页签 / 焦点区循环（左→中→右） |
| `Ctrl-Tab`、`Ctrl-1..9` | 中栏 | 标签页切换 |
| `Ctrl-P` | 全局 | 命令面板（所有动作的模糊搜索入口） |
| `Ctrl-N` | 全局 | 新会话 |
| `Ctrl-M` | 输入区 | 权限模式切换 |
| `Ctrl-T` | 输入区 | 思考强度切换 |
| `Enter` | 各区 | 展开/打开/发送（按区） |
| `d` / `f` | 左栏会话 | 删除 / fork |
| `q` | 弹窗外 | 关闭当前标签页（输入框为空时） |
| `Ctrl-C`×2 | 全局 | 退出 TUI（daemon 存活） |

## 8. 组件与 pi-tui 映射

| ponda 组件 | pi-tui 基件 | 备注 |
|---|---|---|
| App/Header/StatusBar | VStack + 自定义 render | 差分渲染、同步输出由 pi-tui 保证 |
| 左栏会话/文件树 | ScrollView + 树组件（自研，组合 SelectList 交互） | 虚拟滚动支持长列表 |
| 中栏消息流 | ScrollView + Markdown | 增量 append，自动跟随底部（用户上滚即停） |
| 输入区 | Editor | @ 与 / 的补全层自研（Overlay） |
| 标签页行 / 子 agent 条 / chips | HStack 自定义 | |
| 折叠块 | 自定义（.CollapsedRow + 惰性展开） | 展开内容缓存 |
| 弹窗 | Overlay + SelectList | §6 |

新增组件落在 fork 的 tui 包补丁区域内（`PATCHES.md` 登记），均为纯 render + 事件函数，可用 pi-tui 的 VirtualTerminal 做无头快照测试。

## 9. 边界情况与开放问题

- **超大文件打开**：>2MB 文件标签页分页加载（只读分页器），提示 agent 处理而非全量渲染。
- **多环境切换**：TUI 内 `Ctrl-P e` 切换环境 = 重连另一 daemon（当前 attach 状态保留在原 daemon）；Header 即时更新。
- **终端能力探测**：真彩/图片协议/同步输出启动时探测并降级；`ponda tui --capabilities` 打印探测结果。
- **OQ**（00 §9 Q4）：数学公式的第二级方案（预渲染六增量图像）是否值得引入，取决于用户反馈频率。
- **OQ**：鼠标支持范围（点击标签页/链接/折叠行）在不同终端的差异较大，先保证键盘完备、鼠标尽力。
